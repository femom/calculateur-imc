# Calculateur d'IMC

Projet réalisé dans le cadre de la **Semaine 7 — JS Fondamentaux** (niveau Débutant) du parcours Fullstack **Akieni Academy** (Cohorte 2 — 2026).

## Description

Une page web qui calcule l'Indice de Masse Corporelle (IMC) pour plusieurs profils et affiche le résultat avec sa catégorie, en couleur.

## Fonctionnement

- La fonction `calculerIMC(poids, taille)` calcule l'IMC selon la formule : `poids / (taille * taille)`
- La fonction `determinerCategorie(imc)` retourne la catégorie correspondante (maigreur, normal, surpoids, obésité)
- Chaque résultat est affiché dans la page via la fonction `afficher()`, avec une couleur selon sa catégorie
- 4 profils de test sont calculés au chargement de la page

## Compétences JavaScript travaillées

- Variables (`let`, `const`) et types (`number`, `string`)
- Opérateurs arithmétiques et de comparaison
- Conditions `if / else if / else`
- Fonctions avec paramètres et `return`
